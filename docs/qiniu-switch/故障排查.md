# 故障排查

## 数据库 v20，应用仅支持 v19

这表示**程序旧于数据库**，不是数据库坏了。常见情况是从旧的 `src-tauri/target/release/bundle/macos/Qiniu Switch.app` 启动了 3.20.4 程序；更新项目源码不会自动替换已打包的 `.app`。先用“退出”或 ⌘Q 关闭旧程序，再安装和打开 4.0.6 或更新的 Qiniu Switch。

可只读核对数据库与本地旧安装包：

```bash
sqlite3 ~/.qiniu-switch/qiniu-switch.db 'PRAGMA user_version;'
plutil -extract CFBundleShortVersionString raw -o - 'src-tauri/target/release/bundle/macos/Qiniu Switch.app/Contents/Info.plist'
```

若依次得到 `20` 与 `3.20.4`，就与截图中的错误一致。**不要删除 `qiniu-switch.db`，不要把 `user_version` 改成 19。** 备份整个 `~/.qiniu-switch/` 后再安装新版。当前自动更新未启用，错误页不会自动下载新程序。

## 3000 端口被占用

已有开发版 Vite 在运行。先在旧开发终端按 Ctrl+C，再执行 `pnpm dev`；不用同时开两个桌面开发进程。

## 浏览器里能看界面，配置却不生效

`pnpm dev:renderer` 只有 React 网页。要写入 Claude Code、Codex 等客户端配置，需启动 Tauri 桌面版：

```bash
pnpm dev
```

## 模型数量与网页目录不一致

“探索模型”只计当前筛选条件下未退役且可用的目录模型；退役和暂不可用模型仍可在折叠区查看。连接 Key 后的“可用模型”只统计 `/v1/models` 返回、且未被目录标记退役/不可用的 ID。目录与 Key 权限变化可能导致数量不同。若接口失败，不把错误当作 0 个模型。

## 分享 DMG 给其他 Mac

使用 `--target universal-apple-darwin --bundles dmg` 构建，使用 `lipo -archs` 核对安装包内二进制包含 `arm64 x86_64`。未做 Apple 公证的本地包可能被 Gatekeeper 拦截；应通过正式签名和公证后再公开分发。
