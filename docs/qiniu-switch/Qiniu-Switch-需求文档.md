# Qiniu Switch：当前功能与验收范围

更新：2026-10-10。代码基线：CC Switch v4.0.6 + Qiniu Switch 扩展。

## 用户流程

1. 安装当前桌面程序，从侧边栏进入“模型广场”。
2. 浏览七牛公开模型目录；筛选、查看详情和价格。退役及不可用模型单列，不计入可用数量。
3. 输入模型 API Key，连接 `/v1/models`，从该 Key 实际返回的模型中选择；已知退役/不可用 ID 及别名排除在可用列表外。
4. 对支持应用内对话的模型进行试用，或选择兼容客户端保存供应商配置，再在客户端中验证实际调用。
5. 如需管理信息，在“授权中心”输入七牛 AK/SK 查询 Key、用量、账单和日志。AK/SK 不等于模型 API Key。

## 已实现的能力

| 能力           | 当前行为                                                                      | 验收边界                                             |
| -------------- | ----------------------------------------------------------------------------- | ---------------------------------------------------- |
| 最新上游界面   | v4.0.6 侧边栏、应用页及供应商搜索；保留直连、路由、聚合等上游能力。           | 聚合只对支持的客户端开放。                           |
| 模型广场       | 读取七牛公开目录、模型详情、厂商图标、价格与能力；支持搜索和筛选。            | 目录状态随上游变化，详情不代表 Key 已获授权。        |
| 可用模型       | 从目录中排除已退役/不可用项；连接 Key 后与 `/v1/models` 的 ID/别名核对。      | API 返回但目录未收录的 ID 无法根据目录判定退役状态。 |
| 模型试用与配置 | 支持的文本模型可用当前会话 Key 试用；保存到兼容客户端时沿用项目供应商机制。   | “配置成功”不等于第三方客户端真实请求成功。           |
| 专属网页导入   | `qiniuswitch://v1/import`、风险预览、客户端图标选择、模型接口选择、用户确认。 | 仓库 HTML 为本地 Mock；正式控制台接入未完成。        |
| 管理认证       | AK/SK 签名验证、只读管理查询、响应脱敏。                                      | 不提供网页登录 Cookie；不开放创建、删除或禁用 Key。  |
| 客户端扩展     | WorkBuddy、Antigravity 入口与适配；WorkBuddy 记忆文件可编辑。                 | 第三方客户端版本、认证注入和真实调用仍须逐项验收。   |
| 独立产品数据   | 独立应用标识、协议、图标和 `qiniu-switch.db`；自动更新关闭。                  | 新安装包须手动分发与安装。                           |

## 明确不包括

- 自动登录七牛控制台、自动读取未脱敏的模型 Key 或 Token Plan 套餐详情。
- 借助 AK/SK 代替模型 API Key 调用模型。
- 把本地 Mock 页当作正式控制台页面发布。
- 在缺少目标客户端真实调用验证时宣称所有模型或客户端可一键使用。

## 发布前检查

运行类型检查、前端测试、Rust 测试和双架构打包；用数据库副本先验证迁移，再检查安装包版本。Mac 上的通用 DMG 应用程序须同时包含 `arm64` 与 `x86_64`。手动签名/公证未完成前，其他 Mac 首次打开可能触发系统安全提示。
